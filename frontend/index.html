Methodology

How ASTRAIL turns public orbital element sets into a risk-ranked alert feed.

01 · Data ingestion

ASTRAIL pulls Two-Line Element (TLE) sets from CelesTrak, a free, public, no-signup catalog of tracked orbital objects. Responses are cached on disk for 30 minutes. If CelesTrak is unreachable, ASTRAIL falls back to the last good cache, then to a fully offline, checksum-valid synthetic catalog ("Demo Mode") so the dashboard is never blank.

02 · Propagation

Every object is propagated with SGP4 — the standard model CelesTrak's own elements are designed for — producing position and velocity in the TEME frame at any requested instant. Because both objects in a pair are evaluated in the same frame at the same instant, relative distance is frame-independent, so no extra coordinate conversion is needed for conjunction screening.

03 · Conjunction search

Every object pair is scanned in two passes: a coarse scan (5-minute steps) across the full look-ahead window locates candidate local minima in separation distance, then a fine scan (10-second steps) around each candidate refines the true time and distance of closest approach (TCA).

04 · Risk scoring

Each event gets a 0–100 score blending three weighted components:

  • Proximity (62%) — closer miss distance relative to your alert threshold.
  • Kinetic severity (28%) — higher relative velocity means a more destructive impact.
  • Data confidence (10%) — older TLE epochs carry more positional uncertainty.

05 · ASTRAIL Risk Index

A single 0–100 dial summarizing catalog-wide risk. This is an ASTRAIL-designed aggregate indicator, not an established or peer-reviewed standard — it is inspired by the cascading-collision risk associated with the Kessler effect, but the formula is our own: 70% from the average of the five highest-risk events in the window, 30% from how many risky conjunctions are piling up relative to catalog size.

Limitations

This is a triage and demonstration tool, not a certified conjunction-assessment system. It does not model covariance/uncertainty ellipsoids, maneuver plans, or atmospheric drag beyond what SGP4 itself accounts for. For operational decisions, refer to official sources such as the U.S. Space Force's CARA program.
